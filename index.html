Project Overview

This project demonstrates a CI/CD workflow for deploying a web application from a GitHub repository to AWS Elastic Beanstalk using AWS CodePipeline. The pipeline supports development deployment, manual approval, and production deployment.

Technologies Used

GitHub

Stores application source code and tracks code changes through version control.

AWS CodePipeline

Automates the movement of source code through deployment stages.

Elastic Beanstalk

Provides a managed environment for deploying and running the web application.

PHP & HTML

Application platform and web content used for the project demonstration.

Amazon EC2

Provides compute capacity used by the Elastic Beanstalk environment.

Amazon SNS

Used to support notification delivery for the manual approval workflow.

CI/CD Deployment Workflow

01. GitHub Source

Developer commits web application code to the GitHub repository.

02. AWS CodePipeline

Pipeline detects the source change and starts the deployment workflow.

03. Development Deployment

Application is deployed to the development Elastic Beanstalk environment.

04. Manual Approval

Deployment requires approval before proceeding to production.

05. Production Deployment

Approved changes are deployed to the production Elastic Beanstalk environment.

Project Objective

Demonstrate automated application deployment, source code integration, environment management, and controlled production releases using AWS cloud services.
